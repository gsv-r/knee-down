# Knee Down

**Knee Down** is a launcher for **GP Bikes** designed to make everyday play easier. It brings game launching and mod management — bikes, riders, paint jobs, tracks and tires — together in one simple, organized interface.

## Download and install

Knee Down is available for **Windows (x64)**.

1. Go to the latest release page: https://github.com/gsv-r/knee-down/releases/latest
2. Download the installer **`KneeDown.exe`**.
3. Run the downloaded file and follow the on-screen instructions.

> The `latest.yml` and `.blockmap` files in the release are internal to the automatic update system — you don't need to download them.

## Updates

If you already have Knee Down installed, updates are downloaded and applied automatically. You can also download the latest installer from the link above and run it again at any time.
